Public Workflow Summary｜公开工作流总结

Claude Design → Claude Code Redesign Workflow Claude Design → Claude Code 重设计工作流

A two-prompt workflow for redesigning an existing production app with AI while keeping product logic safe. 中文：这是一个双提示词流程，用 AI 重设计已有产品，同时保护后端逻辑、权限、计费和核心功能不被误改。

Core split｜核心拆分： Claude Design explores taste, product-fit UX, visual direction, tokens, components, and page plans. Claude Code implements the approved design in the real repo with tests, build checks, browser comparison, and a PR. 中文：Claude Design 负责设计判断；Claude Code 负责安全落地。

Why split｜为什么拆分 Files｜文件 Workflow｜流程 Style direction｜风格方向 Verification｜验证

Why This Workflow Exists ｜为什么需要这个流程

Good AI redesign needs taste and safety. 中文：好的 AI 重设计既要有审美判断，也要保护产品逻辑。

Design first｜先设计

Do not let implementation choose the taste｜不要让实现阶段决定审美

Claude Design should audit the current UI, explore directions, and define the design system before code changes begin. 中文：先让 Claude Design 做审美和结构判断，再进入代码实现。

Preserve behavior｜保护行为

Redesign is not a product rewrite｜重设计不是重写产品

The app should keep its backend/API/auth/billing/product behavior unless the user explicitly approves product changes. 中文：没有明确批准，就不要改变后端、接口、权限、计费或核心流程。

Verify visually｜视觉验证

Code review is not enough｜只看代码不够

Claude Code must open the rendered app, compare it against the approved design export, test responsive states, and check console errors. 中文：必须看真实页面效果，而不只是读代码。

The Repository Files ｜GitHub 仓库里的文件

Each file has a distinct role so users do not have to invent the process every time. 中文：每个文件各司其职，让用户不用每次重新组织流程。

redesign-prompt.md

Claude Design prompt｜给 Claude Design 的提示词

Audits the existing app, proposes creative directions, defines the design system, specifies components, plans pages, and produces a redesign-specific HANDOFF.md. 中文：负责探索、设计系统、组件和页面计划。

redesign-handoff.md

Claude Code handoff｜给 Claude Code 的交接提示词

Implements the approved design in the real app while preserving behavior, working on a branch, verifying with lint/typecheck/build, and opening a PR. 中文：负责在真实仓库安全实现。

claude-code/commands/redesign.md

Optional /redesign command｜可选 /redesign 命令

Install it into .claude/commands/redesign.md so the handoff can be reused without pasting the full prompt every time. 中文：安装后可直接运行命令。

design-inspiration/

Reference material｜设计参考资料

A place for screenshots, links, notes, and style preferences. References are for principles, not copying another product exactly. 中文：参考是为了描述原则，不是复制别人。

The 6-Step Workflow ｜6 步工作流

Start with context, end with a verified redesign branch and PR. 中文：从整理上下文开始，到完成已验证的重设计分支和 PR。

Prepare app context｜准备产品上下文

Collect the app repo link, current screenshots, pain points, inspiration, and constraints Claude must preserve. 中文：准备仓库、截图、问题、参考和不能破坏的限制。

Run Claude Design｜运行 Claude Design

Use redesign-prompt.md to audit the app, explore style directions, define tokens/components, and create a page-by-page redesign plan. 中文：先做审美、结构和体验设计。

Pick or refine the direction｜选择或微调方向

React in normal language: “warmer,” “less generic,” “more editorial,” “more serious developer tool.” 中文：用自然语言反馈风格偏好。

Download the Claude Design ZIP｜下载 Claude Design ZIP

Do not rely only on a share link. Download and unzip the approved design export into the app repo so Claude Code can inspect real files. 中文：不要只给分享链接，要下载并解压设计文件。

Hand off to Claude Code｜交给 Claude Code 实现

Use the installed /redesign command or redesign-handoff.md. Claude Code should create a redesign branch and implement tokens, components, then pages. 中文：用专门分支按阶段实现。

Verify and open PR｜验证并开 PR

Run checks, compare the rendered app against the design export in a browser, capture evidence when possible, push the branch, and open a PR for review. 中文：验证真实页面后再推送和开 PR。

Choosing a Style Direction ｜如何选择风格方向

You do not need perfect taste words upfront. 中文：一开始不需要说出完美的风格词。

1

Evolutionary｜渐进型

Improves the current product while still changing layout and hierarchy meaningfully. 中文：保留熟悉感，但明显改善结构和层级。

2

Strong-fit bold｜强匹配大胆型

The best balanced recommendation for the product name, audience, workflow, and desired style. 中文：最适合产品定位和用户场景的大胆版本。

3

Revolutionary｜突破型

More distinctive and opinionated; changes composition, interaction patterns, and storytelling while preserving behavior. 中文：更有记忆点，但仍保护产品功能。

A redesign should improve how the product feels, reads, and works — not only its colors. 中文：重设计应该改善产品的感受、理解和使用方式，而不只是换颜色。

Claude Code Verification Checklist ｜Claude Code 验证清单

The implementation is not done until the real app is checked. 中文：真实页面验证之前，不要说完成。

  • Approved Claude Design export is local｜已把批准的设计导出放到本地
  • HANDOFF.md checked if present｜如有 HANDOFF.md，已读取
  • Dedicated redesign branch created｜已创建专门重设计分支
  • Backend/API/auth/billing behavior preserved｜后端、接口、权限、计费行为保持不变
  • Tokens and shared components implemented before pages｜先实现设计变量和共享组件
  • Lint, typecheck, and build pass or caveats documented｜规范、类型和构建通过，或记录限制
  • Rendered app opened in a browser｜已在浏览器打开真实应用
  • Actual UI compared against the design export｜已对照设计导出检查视觉还原
  • Responsive states checked｜已检查响应式状态
  • Browser console checked｜已检查浏览器控制台
  • Screenshots or recording captured when available｜可行时已截图或录屏
  • Branch pushed and PR opened for human review｜已推送分支并开 PR 供人工审查

Think of this as a relay race, not one giant prompt. 中文：把它当作接力赛，而不是一个超长提示词。

Safety rule｜安全规则

Visual change, product-safe｜视觉改变，产品安全

Keep important flows, permissions, errors, legal content, and destructive actions visible and working. 中文：重要流程、权限、错误、法律内容和危险操作不能被隐藏或破坏。
